# words

把**你自己的单词表**变成一个会按遗忘曲线复习的背单词 App。

白底，中间一个大写 **W**。没有广告、没有社交、没有商店、不联网也能用。

---

## 一、怎么打开

### 电脑上先看

```powershell
cd words-app
python -m http.server 8765 --bind 0.0.0.0
```

然后浏览器打开 <http://127.0.0.1:8765>

### 手机上用（最好玩的一步）

1. 手机和电脑连**同一个 WiFi**；
2. 在手机浏览器打开 `http://你电脑的局域网IP:8765`（比如 `http://192.168.1.5:8765`）；
3. 打开后：
   - **iPhone（Safari）**：点底部分享 → 「添加到主屏幕」；
   - **安卓（Chrome / Edge）**：右上角菜单 → 「添加到主屏幕」或「安装应用」。
4. 从桌面点开，全屏、没有地址栏，和装了个 App 一样。

> 想真正做成可安装的 PWA，需要 https 地址；局域网 http 也能用，只是不能触发「安装」提示。数据都存在手机浏览器里，换设备不会同步。

## 二、能干什么

| 功能 | 说明 |
|---|---|
| 导入单词表 | .docx / .pdf / .txt，自动识别 **单词 · 音标 · 词性 · 中文** |
| 校对 | 导入后先让你确认，识别不确定的标黄，可以逐条改 / 删 |
| 背单词 | 先只给你 **单词 + 音标**，点一下才露中文；底部「会了 / 不认识」 |
| 遗忘曲线 | 9 个阶段 `0,1,2,4,7,15,30,60,120` 天，会了往后走，不认识往回退 |
| 当天重排 | 不认识 5 分钟后在今天的队列里再出现一次，同一个词一天最多 3 次 |
| 新词抽取 | **只从「还没学过」的词里随机抽**，学过的绝不混进新词 |
| 每日任务 | 每天目标 = 到期复习 + 你设定的新词量 |
| 打卡 | 连续天数、累计天数、本月日历、一句鼓励语（30 条，按天数分级） |
| 统计 | 今日正确率、120 天热力图、未来 7 天复习预测 |
| 其他 | 撤销、收藏、左右滑手势、发音、深色模式、导出 / 恢复备份 |

### 什么格式的文档认得出来

一行一个词条，最常见的几种写法都行：

```
abandon /əˈbændən/ vt. 放弃；抛弃
abandon  [əˈbændən]  v. 放弃
abandon v. 放弃 n. 放任          ← 一行多词性
abandon                          ← 两行一条也行
vt. 放弃；抛弃
```

Word 表格也支持：`单词 | 音标 | 词性 | 中文`（列的先后顺序不重要，程序按内容类型判断）。

**扫描图片版 PDF 读不出文字**，会直接告诉你换 Word 版，不会假装成功。

## 三、算法

```
intervals = [0, 1, 2, 4, 7, 15, 30, 60, 120]   // 天，索引 = stage

会了：      stage += 1  →  下次 = 今天 0 点 + intervals[stage] 天
不认识：    stage = max(1, floor(stage/2))
            下次 = 现在 + 5 分钟，并且当天队列尾部再出现一次
            同一个词一天最多重排 2 次，第 3 次直接放到明天
已掌握：    stage 走到 8 且连续答对 3 次 → 退出复习队列
```

- 逾期不补作业：只按「逾期最久优先」排进今天的队列，一次出现就重新算；
- 每日复习上限默认 200，超出的顺延到明天；
- 记忆持久度 = `stage / 8`，只用来显示。

## 五、数据

- 全部存在**浏览器本地**（IndexedDB），不上传任何地方；
- 「我的 → 导出备份」可以存一份 JSON，换浏览器时导入恢复；
- 清浏览器数据 = 数据没了，记得导出。

---

## 六、已知边界

- 扫描件 PDF 不支持（没有 OCR）；
- 同一个词在词库内会去重（默认保留第一次出现的释义）；
- 没有云同步 / 多设备；
- 发音用系统 TTS，效果取决于手机自带的语音包；
- 局域网 http 打开时 service worker 不注册（离线缓存只在 https / localhost 生效）。
